# real-estate-profile 通用房地产档案

## 核心铁律（最高优先级）

1. **实时数据必须来自 anysearch**：所有具体房产数据（价格、成交、配套、宏观等）必须通过 anysearch 实时搜索获取（当前环境已保证搜索时稳定触发，无需配置 anysearch 本身）。严禁凭训练数据/记忆回答任何具体数据。
2. **禁止编造**：无法获取的字段写「暂无数据」并注明尝试过的数据源；不确定的价格必须标注口径。
3. **数据时效必标**：所有输出首部标注 `> 📅 数据抓取日期：YYYY-MM-DD`。

## 工作流

1. 识别需求：小区/楼盘档案、宏观行情、多盘对比
2. 提取输入参数：城市/区域（必填）、小区/楼盘名（必填，可含别名）、需求类型、深度
3. 通过 anysearch 实时搜索（建议一次 3 条并行查询：①"{小区/楼盘/区域} 新房 楼盘" ②"{小区/楼盘} 在售 价格 成交" ③"{小区/楼盘} 开发商 物业 配套"），必要时抓取详情页
4. 交叉验证多个数据源，标注不一致
5. 按对应模板输出（见附录 A-E），缺失字段写「暂无数据」
6. 末尾必含「数据来源」列表与「数据缺口清单」
7. 如需存档，用文档工具保存为档案文档

## 输入约定

| 参数 | 必填 | 说明 |
|---|---|---|
| 城市/区域 | ✅ | 用于消歧与定位官方渠道 |
| 小区/楼盘名 | ✅ | 可含别名，做模糊匹配 |
| 需求类型 | ✅ | `小区档案` / `宏观数据` / `多盘对比`（对比=逐个建档再横向比） |
| 深度 | 可选 | `快速`（价格+评分）/ `完整`（全字段） |

## 输出约定（必填区块，缺一不可）

1. 首部：`> 📅 数据抓取日期：YYYY-MM-DD`
2. 价格字段必带口径标签：`[挂牌]/[成交]/[报价]/[网签]/[指导价]`
3. 缺失字段：写「暂无数据」并注明尝试过的数据源，禁止编造
4. 配套字段标注兑现状态：已兑现 / 在建 / 规划
5. 开发商/媒体口径形容词（核心区/稀缺/豪宅/TOD 等）须标注"官方/媒体口径自称"，不得当作事实
6. 末尾：`### 数据来源`（URL 列表）+ `### 数据缺口清单`
7. 结束自检：每条关键数据是否带来源与时效

## 附录 D：数据源优先级与降级链（全国通用）

# 数据源优先级与降级链（全国通用）

## 搜索方式
- 所有实时搜索通过 anysearch 完成（当前环境已保证搜索时稳定触发）。
- 按需并行查询，必要时抓取详情页获取结构化数据。

## 数据源优先级
1. **贝壳/链家**（ke.com / lianjia.com）— 二手房/新房/成交/户型最全
2. **安居客**（anjuke.com）— 小区基础信息完善
3. **房天下**（fang.com）— 历史成交数据
4. **我爱我家**（5i5j.com）— 补充数据
5. **当地官方渠道** — 当地住建委/房管局官网、政府公告、土地出让信息、不动产登记中心
6. **百科类**（百度百科/维基百科）— 基础信息补充

## 说明
- **不写死具体 URL**（会失效），按"入口语义"定位即可
- 城市不同，官方渠道名称与入口不同，以当地为准
- 同一字段尽量交叉验证 ≥2 个来源，标注不一致

## 降级链
- anysearch 搜索 → 详情页抓取（如链家/贝壳详情页）→ 备用手段（由环境层决定）
- 数据源失效/反爬时：换同源其他入口或降级到下一优先级数据源，并如实标注获取方式

## 附录 E：数据质量规则与避坑清单

# 数据质量规则与避坑清单

## 数据质量原则
- ✅ 所有数据标注抓取日期（`> 📅 数据抓取日期：YYYY-MM-DD`）
- ✅ 价格区分口径：`[挂牌]/[成交]/[报价]/[网签]/[指导价]`，禁止把挂牌价描述成成交价
- ✅ 缺失字段写「暂无数据」并注明尝试过的数据源
- ✅ 交叉验证 ≥2 个来源，标注不一致
- ✅ 区分官方数据 / 第三方数据 / 估算，不得混淆
- ✅ 认证/评价数据（如 C-NCAP/E-NCAP、环评等）注明评价版本与年份
- ✅ 关键数据附来源链接 + 采集时间戳

## 避坑清单（血泪教训）
1. ❌ 用训练数据编价格/成交 → 数据滞后误导用户 → 必须实时搜索
2. ❌ 不标数据时效 → 无法判断有效性 → 每条数据必须标抓取日期
3. ❌ 单源数据直接采信 → 可能偏差 → 必须交叉验证
4. ❌ 把"挂牌价"当"成交价" → 系统性高估 → 必带口径标签
5. ❌ 给缺失指标猜分 → 评分失真 → 标"数据缺失，不计分"
6. ❌ 把开发商/媒体话术（核心区/稀缺/豪宅/TOD/潜力大）当事实 → 标注"官方/媒体口径自称"
7. ❌ 规划中的配套按 100% 兑现计算 → 标注"规划中"；学校尤需谨慎（是否确定招生/本部/挂牌/多校划片）
8. ❌ 忽略"数据缺口清单" → 让分析方盲信档案完整性 → 末尾必须列出未采到字段及原因
