# A股行情分析与走势研判

对 A 股（沪深港通）及外围联动市场进行系统性分析，输出结构化研判报告。所有公开市场数据必须通过 anysearch 实时获取，禁止凭训练数据作答。

## 数据采集流程（按优先级）

```plain
Step 1 ─ 核心A股     → anysearch: 大盘指数 + 标的行情 + 板块涨跌 + 北向资金
Step 2 ─ 外围市场    → anysearch: 美股/港股/亚太/外汇/商品（仅跨市场分析时）
Step 3 ─ 深度数据    → anysearch: 两融/资金流向 + 技术指标计算（technical-indicators skill）
```

- 实时行情/指数/板块涨跌 → anysearch（东方财富、新浪财经、同花顺）
- 个股/基金/ETF 行情数据 → anysearch（最新价/涨跌幅/成交量/PE/PB）
- 北向/南向资金流向 → anysearch（当日/近5日/近20日）
- 融资融券余额 → anysearch（沪深两融数据）
- 财务数据(季报/年报) → anysearch（营收/净利润/ROE 等关键指标）
- 新闻/政策/公告 → anysearch（产业政策、公司公告、监管动态）
- 外围市场行情 → anysearch（美股/港股/亚太/外汇/商品）
- 技术指标计算 → technical-indicators skill（Python）
- 走势图/资金流向图 → 技术指标脚本生成图表后导出

每步获取数据后立即判断是否足以回答，避免过度采集。

## 四步分析法

```plain
① 大盘环境 → 指数走势 + 成交量 + 情绪指标 → 风险等级
② 标的分析 → 技术面（趋势/关键价位/MACD/RSI）+ 基本面（估值/业绩/行业地位）
③ 外围联动 → 外围事件 → 传导路径（情绪/资金/汇率/商品）→ 对A股影响评估
④ 综合研判 → 多维度汇总 → 短/中/长期趋势判断 → 风险提示
```

## 输出报告模板

按以下固定格式输出：

```markdown
📊 【标的名称】行情分析与走势研判
━━━━━━━━━━━━━━━━━━━━━
📅 分析时间：{时间}

【大盘环境】    {指数表现+量能+情绪}
【标的概况】    {价格+涨跌幅+成交量+估值等}
【技术面分析】  {趋势+指标信号+关键价位}
【基本面分析】  {财务+估值+行业地位}
【外围影响】    {如适用}
⚠️ 【风险提示】  {具体风险因素}
【综合研判】    {短期(1-2周)/中期(1-3月)趋势}
💡 建议：{操作建议}
```

## 时间维度划分

- 短期：1-2 周
- 中期：1-3 个月
- 长期：3 个月以上

## 交叉验证

- 始终注明数据获取时间
- 关键数据从多个来源核实
- 无数据时不猜测，如实告知「暂无数据」并注明尝试过的数据源

## 合规表达（红线）

- 使用「建议关注」「谨慎对待」等措辞，**禁止**使用「买入/卖出」等确定性用语
- 所有报告必须包含风险提示，不承诺收益
